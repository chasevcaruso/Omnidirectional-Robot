## Omnidirectional Robot
This repository contains code I personally authored as part of a larger robotics project. The goal of the project was to construct and program a robot featuring three motors, each driving a wheel mounted at 120-degree angles on a central plate. I developed the control algorithms to calculate power output ratios for the wheels, allowing synchronized movement including forward driving, strafing, turning in place, and combinations of these motions based on joystick input.

In addition to manual control, I created an autonomous mode that uses a laser distance sensor to navigate and park the robot based on distance readings.

Note: This code represents only the portions of the project that I individually developed.
